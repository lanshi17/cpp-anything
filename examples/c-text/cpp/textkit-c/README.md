## Risks the analyzer flagged

- C has no exceptions: a failure is a return code or an errno, and the port must mirror it
- char* strings: null versus empty is observable, and the recorder treats a null return as null
- Fixed-width C types are not Python's unbounded ints: the signature decides the width
- Undefined behaviour on inputs outside the contract is a case, not a failure (the harness records the signal)
