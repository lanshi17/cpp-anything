# slugify-server — C++ front door

Generated by `cpp-anything app front-door`. The binary owns the CLI's entry point:
a command that has been wired answers natively, everything else execs the original
(python3 server.py) with the same arguments, so stdout, stderr, exit code and signals are identical.

- routes: none yet
- kill switch: `CPPAN_UNIT_<NAME>=original` forces a unit back to the original
- force everything back: `CPPAN_FORCE_FALLBACK=1`
- fallback log: `CPPAN_FALLBACK_LOG=<path>` gets one line per fallback

`cpp-anything app replay . --build <this binary>` compares it case by case;
`cpp-anything app lift .` refuses while any case still falls back.

```sh
cmake -S . -B build && cmake --build build -j
./build/cppan_app --help
```
