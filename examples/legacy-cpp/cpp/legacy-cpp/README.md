## Modernization is the job

`gate` fails on `NULL`, `malloc`/`free`, raw `new`/`delete`, `char*` string calls,
`printf`, C-style casts and `typedef struct` left in `src/port.cpp`, unless a line (or
the comment block right above it) says `// C-STYLE: why`.

Use the facilities `include/cppan/profile.hpp` reports: `CPPAN_HAS_SPAN` for
`std::span`, `CPPAN_HAS_RANGES` for views and algorithms, `CPPAN_HAS_FORMAT`/
`CPPAN_HAS_PRINT` for formatting, `CPPAN_HAS_STRING_VIEW`-class facilities are C++17
and always available here. Each mapping the analyzer printed above names the macro its
replacement needs.
